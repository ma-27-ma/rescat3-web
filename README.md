# Rescat3 Web

Responsive UX/UI design project for a public-interest website promoting the 3Rs: reduce, reuse and recycle.

## About the project

Rescat3 Web is a responsive web design concept focused on promoting sustainable habits through the principles of **reduce, reuse and recycle**.

The project explores how information can be structured and presented in a clear, accessible, and engaging way across different screen sizes.

## Prototype

The project includes an interactive responsive prototype designed in Figma.

**Tools:** Figma, UX/UI Design, Responsive Design

## Project goals

* Create a clear and accessible information architecture.
* Design a responsive experience for different devices.
* Communicate sustainability concepts effectively.
* Develop a consistent and user-centered interface.
